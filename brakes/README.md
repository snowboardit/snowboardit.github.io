# Notes - 2014 CX-5

- Lug
  - Size: 21mm
  - Torque: 80–108 ft-lbf
- [Front](https://www.mcx5.org/front_brake_disc_removal_installation-913.html):
  - Caliper slide pin bolt:
    - Size: 14 mm
    - Torque: 23-28 ft-lbf
  - Caliper bolt
    - Size: 17mm
    - Torque: 68-81 ft-lbf
- [Rear](https://www.mcx5.org/rear_brake_disc_removal_installation-916.html):
  - **Imperative: Check for electronic parking brake and disable, if present**
  - Caliper slide pin bolt:
    - Size: 14 mm
    - Torque: 17-22 ft-lbf
  - Caliper bolt:
    - Size: 17 or 14mm?
    - Torque: 38-48 ft-lbf
